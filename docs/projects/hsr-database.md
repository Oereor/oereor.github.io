## 简介

这个项目的灵感来源于 [nanoka.cc](https://hsr.nanoka.cc)。

最早是因为 Codex 的额度烧不完急需一个方式快速消耗额度，但是初版不加任何约束的情况下做出来的东西惨不忍睹。项目就被搁置了一段时间。~~后来额度又烧不完了所以就有了改良版的网站~~

开发过程的主要精力都花在[研究乱七八糟的配置文件](../notes/turn-based-game-data-analysis.md)上了。**代码全部是 Codex 写的。**
